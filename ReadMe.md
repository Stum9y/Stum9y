## 🏠 Homelab Overview

My homelab is my **main learning and testing environment**, where I safely experiment with real‑world technologies and scenarios.

Using **Proxmox**, with both **Windows and Linux VMs**, I recreate enterprise‑style environments to test:
- Infrastructure changes and upgrades  
- Automation workflows  
- Identity, access, and DNS behaviour  
- Backup, snapshot, and recovery processes  

This setup reinforces good habits around **documentation, version control, and structured change**, and bridges the gap between theory and real‑world experience.

### 🧩 Services I Run
- ⚙️ **Ansible Semaphore** – automation and configuration management  
- 🧑‍💻 **Gitea** – self‑hosted Git and version control  
- 🌐 **DNS Server** – internal name resolution  
- 🪟 **Windows VMs** – AD, Group Policy, admin scenarios  
- 🐧 **Linux VMs** – automation, services, CLI practice
